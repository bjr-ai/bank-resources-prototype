# Bank Resources homepage prototype

This is a small static website: no WordPress, database, or paid service is required.

## Preview it

Double-click `index.html`. It will open in your web browser.

## Publish it free with GitHub Pages

1. Sign in at [github.com](https://github.com).
2. Click the **+** at the top right, then **New repository**.
3. Name it `bank-resources-prototype` and choose **Public**.
4. Check **Add a README file**, then click **Create repository**.
5. Click **Add file**, then **Upload files**.
6. Drag in `index.html`, `styles.css`, `script.js`, and the entire `assets` folder from this project.
7. Click **Commit changes**.
8. Open the repository’s **Settings**, then click **Pages** in the left sidebar.
9. Under **Build and deployment**, select **Deploy from a branch**.
10. Choose the `main` branch and `/ (root)`, then click **Save**.

GitHub will show the public address after a minute or two. It will usually look like:

`https://bjr-ai.github.io/bank-resources-prototype/`
